# Image Duplicate Finder

Απλή εφαρμογή Windows (Python + Tkinter) που βρίσκει **την ίδια εικόνα** ακόμα κι
όταν έχει διαφορετικό όνομα, μέγεθος ή συμπίεση — π.χ. όταν οι ίδιες φωτογραφίες
κατέβηκαν άλλες από Viber και άλλες από Messenger.

**Δεν διαγράφει ποτέ καμία εικόνα.** Οι διπλότυπες μετακινούνται σε υποφάκελο
`duplicates` μέσα στον φάκελο που διάλεξες, και κρατιέται πάντα μία έκδοση.

---

## Χαρακτηριστικά

- **Drag & drop φακέλου** πάνω στο παράθυρο (ή επιλογή με το κουμπί «Επιλογή...»).
- Σαρώνει και **υποφακέλους**.
- Ανιχνεύει ίδιες εικόνες με **perceptual hash (pHash + dHash)**, ανεξάρτητα από
  όνομα αρχείου, ανάλυση, format (JPG/PNG/WEBP/...) ή ποιότητα συμπίεσης.
- Σέβεται τον προσανατολισμό **EXIF** (φωτογραφίες κινητού).
- Ρυθμιζόμενη **ανοχή ομοιότητας** (μικρότερη = πιο αυστηρή).
- Κρατάει αυτόματα την **καλύτερη έκδοση** της ομάδας (μεγαλύτερη ανάλυση, μετά
  μεγαλύτερο αρχείο).
- Πριν τη μετακίνηση δείχνει αναλυτικά τις ομάδες, ώστε να τις ελέγξεις.
- **Καμία διαγραφή**: τα αρχεία πηγαίνουν στον φάκελο `duplicates` και μπορείς να
  τα επαναφέρεις.

## Εκτέλεση

### Έτοιμο `.exe` (χωρίς Python)

Κατέβασε το `ImageDuplicateFinder.exe` από τα
[**Releases**](https://github.com/eazyfixgr/image-duplicate-finder/releases) και
τρέξε το.

> Τα Windows SmartScreen μπορεί να προειδοποιήσουν επειδή το exe δεν είναι
> ψηφιακά υπογεγραμμένο. Πάτα «More info → Run anyway».

### Από τον κώδικα

```bat
pip install -r requirements.txt
run.bat
```

ή απευθείας:

```bat
py image_duplicate_finder.py
```

Απαιτούνται **Python 3.9+**, `pillow`, `numpy` και (προαιρετικά, για drag & drop)
`tkinterdnd2`.

---

## Χρήση

1. Άνοιξε την εφαρμογή.
2. Σύρε έναν φάκελο πάνω στο παράθυρο — ή πάτα «Επιλογή...».
3. Ρύθμισε την «Ανοχή ομοιότητας» αν χρειάζεται (προεπιλογή **8 / 64**).
4. Πάτα **«Σάρωση για διπλότυπα»** και περίμενε να τελειώσει.
5. Έλεγξε τη λίστα με τις ομάδες.
6. Πάτα **«Μετακίνηση στο duplicates»**.

Τα μοναδικά αρχεία μένουν στη θέση τους. Οι διπλότυπες εκδόσεις μετακινούνται
στον φάκελο:

```
<ο φάκελος που διάλεξες>\duplicates\
```

Αν υπάρχει ήδη αρχείο με το ίδιο όνομα, προστίθεται αυτόματα ` (2)`, ` (3)` κ.ο.κ.

## Πώς λειτουργεί

Για κάθε εικόνα υπολογίζεται:

- **pHash** σε 32×32 grayscale μέσω DCT (64 bits) — ανθεκτικό σε αλλαγή μεγέθους
  και επανασυμπίεση.
- **dHash** (64 bits) ως δεύτερος έλεγχος.
- Ο **λόγος διαστάσεων** ως φίλτρο, ώστε διαφορετικές φωτογραφίες με παρόμοιο
  hash να μην ομαδοποιούνται κατά λάθος.

Δύο εικόνες θεωρούνται ίδιες όταν η διαφορά pHash είναι εντός της ανοχής (ή η
διαφορά dHash είναι πολύ μικρή), με συμβατό λόγο διαστάσεων.

---

## Σημειώσεις

- Σε **πολύ χαλαρή ανοχή** μπορεί να ομαδοποιηθούν παρόμοιες αλλά διαφορετικές
  φωτογραφίες. Γι' αυτό υπάρχει η λίστα ελέγχου πριν τη μετακίνηση.
- Η σάρωση γίνεται τοπικά, χωρίς internet και χωρίς αποστολή εικόνων πουθενά.
- Τα αρχεία στον `duplicates` δεν διαγράφονται από την εφαρμογή.

## Build του `.exe`

```bat
py -m PyInstaller --noconfirm --clean --onefile --windowed ^
    --name ImageDuplicateFinder --collect-all tkinterdnd2 ^
    image_duplicate_finder.py
```

Το αποτέλεσμα βγαίνει στο `dist\ImageDuplicateFinder.exe`.
